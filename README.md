# AI Tender Intelligence Platform

AI-powered platform for automated tender analysis, clause extraction, BOQ analysis, and risk identification using FastAPI, OpenAI, LangChain, PostgreSQL, and OCR technologies.

## Features
- Tender PDF Upload
- OCR for scanned documents
- AI Clause Extraction
- BOQ Analysis
- Risk Detection
- Tender Summarization
- Dashboard Analytics
- PDF/Excel Report Export

## Tech Stack
- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- OpenAI
- LangChain
- HTML/CSS/JavaScript
- Tesseract OCR
